2. Brian boleh jelasin ga cara kerja kode gambar yang bergerak itu?
Jawaban :
Kode ini bekerja dengan cara mengambil data logo dari database menggunakan PHP. Setiap data yang ada di tabel `stations` akan ditampilkan menjadi gambar melalui tag `<img>`. Setelah semua gambar ditampilkan, CSS dengan `display: flex` membuat logo-logo tersebut berjajar ke samping dalam satu baris. Selanjutnya, CSS `animation: scrollLogo 30s linear infinite` membuat seluruh kumpulan logo bergerak dari kanan ke kiri secara otomatis. Karena animasinya menggunakan `infinite`, pergerakan logo akan terus berulang tanpa berhenti. Selain itu, aturan CSS seperti `height: 60px` dan `object-fit: contain` digunakan agar semua logo memiliki ukuran yang rapi dan tidak terlihat gepeng atau terpotong meskipun ukuran gambar aslinya berbeda-beda. Jadi, secara sederhana, PHP bertugas mengambil gambar dari database, sedangkan CSS bertugas mengatur tampilan dan membuat gambar-gambar tersebut bergerak di halaman website.

3. Apa fungsi display: flex?

Pertanyaan dari Mr.
1. Apa fungsi dari kode 
html {
  cursor: url("../media/roket.png"), auto;
}
di style.css?
Jawaban : Kode ini digunakan untuk mengubah tampilan kursor mouse di website. Saat pengguna membuka halaman web, kursor yang biasanya berbentuk panah akan berubah menjadi gambar roket yang diambil dari file `roket.png` di folder `media`. Jika gambar roket tidak bisa ditemukan atau tidak didukung oleh browser, maka website akan otomatis menggunakan kursor bawaan komputer. Jadi, fungsi utama kode ini adalah membuat tampilan website menjadi lebih menarik dan unik dengan menggunakan kursor berbentuk roket.

2. Apa fugsi tag span?
Jawaban : Tag <span> digunakan untuk membungkus atau menandai sebagian kecil teks agar bisa diberi style atau diubah tampilannya menggunakan CSS maupun JavaScript. Berbeda dengan <div> yang biasanya digunakan untuk membuat sebuah blok atau bagian besar pada halaman, <span> hanya digunakan untuk elemen yang berada di dalam satu baris teks.

3. Bagaimana cara kita bisa menampilkan gambar di website kita?

Untuk menampilkan gambar di website, kita bisa menggunakan tag <img>. Tag ini memiliki atribut src yang digunakan untuk memanggil atau menunjukkan lokasi file gambar yang ingin ditampilkan. Misalnya:

<img src="./media/kodingnext.png" alt="Logo Koding Next">

Pada contoh di atas, browser akan mencari file kodingnext.png yang berada di dalam folder media, lalu menampilkannya di halaman website. Sedangkan atribut alt digunakan sebagai teks alternatif jika gambar gagal dimuat.

Saat memanggil file, kita juga perlu memahami perbedaan antara ./ dan ../:

./ berarti mencari file atau folder dari lokasi file yang sedang dibuka sekarang.
../ berarti naik satu folder ke atas terlebih dahulu, lalu mencari file atau folder yang dituju.

3. CSS yang kita gunakan kali ini termasuk jenis apa ziyad? Inline, Internal, atau Eksternal? lalu apa perbedaannya?
Jawaban : CSS yang kita gunakan pada project ini termasuk CSS Eksternal (External CSS). Saya tahu karena pada bagian <head> terdapat kode:

<link rel="stylesheet" href="./css/style.css" />

Kode tersebut menghubungkan file style.css yang berada di folder css ke halaman website.
CSS itu ada 3 jenis Mr.
1. Inline CSS
CSS ditulis langsung pada tag HTML menggunakan atribut style
2. Internal CSS
CSS ditulis di dalam tag <style> yang berada di file HTML.
3. External CSS
CSS ditulis di file terpisah, misalnya style.css, lalu dihubungkan ke HTML menggunakan tag <link>.
